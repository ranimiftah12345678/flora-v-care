# Design Tokens — Flora V Care

Token desain aplikasi, diambil dari `resources/css/app.css` dan konvensi visual yang sudah berjalan.

## Warna

| Token | Nilai | Penggunaan |
| --- | --- | --- |
| `--wine` | `#a20e49` | Warna aksen utama |
| `--wine-dark` | `#85142d` | Aksen sekunder / hover |
| `--wine-deep` | `#75172b` | Aksen deep / footer |
| `--rose` | `#fff5f7` | Latar halaman |
| `--rose-card` | `#ffedf1` | Kartu / panel putih pink |
| `--rose-soft` | `#fce3e9` | Area lembut / hover ringan |
| `--ink` | `#56142a` | Teks utama |
| `--muted` | `#806873` | Teks sekunder |
| `--gold` | `#f6a600` | Aksen nilai / highlight |

## Tipografi

- Display: `"Playfair Display"` (serif) — judul, angka besar.
- Body: `"Poppins"` (sans) — teks UI.

## Bordir & radius

- Kartu: `14px` (radius), border `#f0e0e6` / `#f0e1e6`.

## Respons

- Mobile-first; breakpoint turunan lebar layar (desktop nav, sidebar) di atas ~768px.
